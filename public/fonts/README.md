# Tipografía

La fuente real **DK Prince Frog** está versionada en:

`src/assets/fonts/DK-Prince-Frog.otf`

La única declaración global `@font-face` vive en `src/styles/global.css` y usa
el peso Regular (400). Esta carpeta `public/fonts` no contiene fuentes y se
mantiene sólo como referencia histórica para no confundir la ruta activa.
